# South Indian Movie-Style Telugu Christian Suno Library — 100 styles

Tollywood/Kollywood production aesthetics applied to Christian song lyrics. Each prompt captures a specific music-director sub-style or Tollywood song archetype, grounded in real filmography research.

## How to use

1. Pick a folder by what you want — composer's signature sound, or song archetype.
2. Drill into a director's folder for the specific sub-style variant you want (each director has 7 variants covering their actual range — slow ballads, mass anthems, folk, devotional, etc.).
3. Open the `.txt`, copy the prompt below `=== SUNO STYLE PROMPT ===`, paste into Suno's "Style of Music" field.
4. Pair with Telugu Christian lyrics from the `telugu-christian-song-writer` skill or `/write-song-quick`.
