# South Indian Movie-Style Telugu Christian Suno Library — 42 styles

Tollywood/Kollywood production aesthetics applied to Christian song lyrics. Each prompt captures a specific music-director signature, Tollywood song archetype, decade vibe, or modern blockbuster sound.

## How to use

1. Pick a folder by what you want — composer's signature sound, song archetype, decade, Tamil-Kollywood feel, or modern blockbuster.
2. Open the file, copy the prompt below `=== SUNO STYLE PROMPT ===`, paste into Suno's "Style of Music" field.
3. Pair with Telugu Christian lyrics from the `telugu-christian-song-writer` skill.
