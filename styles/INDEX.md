# Telugu Christian Suno Style Library — 100 styles

Each file contains a ready-to-paste Suno "Style of Music" prompt. Open the file → copy the prompt below the `===` line → paste into Suno.

## How to pick

1. Browse the folder that matches the **occasion or musical feel** you want.
2. Open the file — header lines tell you what theme/tempo it suits best.
3. The text below `=== SUNO STYLE PROMPT ===` is what you paste into Suno's "Style of Music" field.
4. Pair with lyrics generated by the `telugu-christian-song-writer` skill.
